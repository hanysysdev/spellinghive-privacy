# spellinghive-privacy

Privacy policy for the Spelling Hive app, published with GitHub Pages:
https://hanysysdev.github.io/spellinghive-privacy/

Pages:

- `index.md` → https://hanysysdev.github.io/spellinghive-privacy/ (privacy policy)
- `delete-account.md` → https://hanysysdev.github.io/spellinghive-privacy/delete-account.html (Google Play's account deletion link)

Edit a page and commit; Pages republishes it within a minute or two.

When the policy changes in substance, give it a new version (the "Version" line) and update the version the app asks parents to accept, in the main repository: `privacyPolicyVersion` in `mobile/lib/domain/models/models.dart` and `spellinghive.consent-policy-version` in `backend/src/main/resources/application.yml`.

Pages setting: Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`.
